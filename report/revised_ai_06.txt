## 1. Objective of the correctness proof

For the COT5405 Analysis of Algorithms project, the goal is to prove that the **earliest-finish-time greedy algorithm** always selects the maximum possible number of mutually compatible green-light windows.

The traffic signal scheduling problem is modeled as a classical maximum-cardinality interval scheduling problem.

We will prove that the algorithm is optimal using an **exchange argument**, followed by induction on the remaining scheduling problem.

## 2. Mathematical definitions

Let

\[
W=\{w_1,w_2,\ldots,w_n\}
\]

be a finite set of candidate green-light windows.

Each window \(w_i\) is represented by

\[
w_i=(s_i,f_i)
\]

where:

- \(s_i\) is its starting time.
- \(f_i\) is its finishing time.
- \(s_i<f_i\), so every window has positive duration.

Two windows \(w_i\) and \(w_j\), scheduled in that order, are compatible if

\[
f_i\leq s_j.
\]

The objective is to find a compatible subset \(S\subseteq W\) maximizing

\[
\boxed{|S|}.
\]

The greedy algorithm sorts the windows by ascending finishing time and selects each window whose start time is at or after the previous selected window's finish time.

## 3. Theorem: Optimality of earliest-finish-time scheduling

**Theorem.** Let \(W\) be a finite collection of candidate green-light windows, each having a fixed starting time \(s_i\) and finishing time \(f_i\), with \(s_i<f_i\).

The algorithm that repeatedly selects the earliest-finishing window compatible with the already selected windows produces a **maximum-cardinality subset of mutually compatible windows**.

In other words,

\[
\boxed{|G|=|O|}
\]

where \(G\) is the schedule produced by the greedy algorithm and \(O\) is an optimal schedule.

## 4. Proof using an exchange argument

### Step 1 — Define the greedy and optimal choices

Let \(g\) be the window with the earliest finishing time among all remaining candidate windows.

Let

\[
O=(o_1,o_2,\ldots,o_k)
\]

be an optimal schedule containing the maximum possible number \(k\) of compatible windows, ordered chronologically.

Because \(g\) has the earliest finishing time,

\[
\boxed{f(g)\leq f(o_1)}.
\]

This inequality is the foundation of the exchange argument.

### Step 2 — Replace the optimal schedule's first window

Consider replacing the first window \(o_1\) in the optimal schedule with the greedy window \(g\).

The modified schedule is

\[
O'=(g,o_2,\ldots,o_k).
\]

We must show that this replacement preserves compatibility.

Since \(O\) is a compatible schedule, its second window satisfies

\[
f(o_1)\leq s(o_2).
\]

We also know

\[
f(g)\leq f(o_1).
\]

Combining these inequalities,

\[
f(g)\leq f(o_1)\leq s(o_2).
\]

Therefore,

\[
\boxed{f(g)\leq s(o_2)}.
\]

This means the greedy window \(g\) is compatible with the next window in the original optimal schedule.

Because the remaining windows were already mutually compatible, the replacement does not introduce any conflicts.

For \(k=1\), compatibility with a second window is unnecessary; replacing the only window still gives a compatible schedule.

### Step 3 — Show that optimality is preserved

The modified schedule \(O'\) contains exactly the same number of windows as \(O\):

\[
|O'|=|O|=k.
\]

Since \(O\) was already optimal, \(O'\) must also be optimal.

Thus, **there exists an optimal schedule that begins with the greedy algorithm's first choice**.

This establishes the greedy-choice property.

### Step 4 — Apply the same argument to the remaining windows

After selecting \(g\), the greedy algorithm only considers windows whose starting times satisfy

\[
s_i\geq f(g).
\]

Define the remaining candidate set as

\[
W'=\{w_i\in W:s_i\geq f(g)\}.
\]

The remaining task is to select the maximum number of mutually compatible windows from \(W'\).

This is the same type of interval scheduling problem as the original problem, but with fewer candidate windows.

Because an optimal schedule can begin with \(g\), the remaining \(k-1\) windows of such an optimal schedule form an optimal solution to the subproblem on \(W'\).

If a better compatible schedule existed for \(W'\), combining it with \(g\) would produce a schedule larger than \(k\), contradicting the optimality of \(O\).

Therefore, the problem has **optimal substructure**.

### Step 5 — Complete the proof by induction

We now prove optimality for every finite number of candidate windows.

**Base case:** If there are no candidate windows, the algorithm selects none, which is optimal. If there is exactly one valid window, the algorithm selects it, which is also optimal.

**Inductive hypothesis:** Assume the greedy algorithm produces an optimal compatible schedule for every problem containing fewer than \(n\) windows.

**Inductive step:** Consider a problem containing \(n\) windows.

The exchange argument establishes that an optimal solution exists that includes the greedy algorithm's first selected window \(g\).

After selecting \(g\), the algorithm solves the remaining subproblem \(W'\), which contains fewer than \(n\) windows because \(g\) itself is excluded.

By the inductive hypothesis, the greedy algorithm produces an optimal solution for \(W'\).

Combining \(g\) with this optimal solution produces an optimal solution for the original problem.

Thus,

\[
\boxed{|G|=|O|}.
\]

Therefore, by induction, the earliest-finish-time greedy algorithm always produces a maximum-cardinality compatible schedule.

\[
\boxed{\text{Q.E.D.}}
\]

## 5. Example demonstrating the exchange argument

Consider three candidate windows:

| Window | Start | Finish |
|---|---:|---:|
| A | 0 | 10 |
| B | 2 | 5 |
| C | 5 | 8 |

Suppose we initially consider a schedule beginning with A.

Window A ends at time 10, so it prevents B and C from being selected alongside it.

The greedy algorithm instead chooses B, which finishes at time 5.

Since C starts at time 5, both B and C can be selected:

\[
G=\{B,C\}.
\]

This example illustrates why choosing an earlier-finishing window can preserve more scheduling opportunities.

The formal proof above establishes that this reasoning works for every valid input, not just this example.

## 7. Assumptions required for the proof

The proof is valid under the following conditions:

1. **Fixed intervals:** Every green-light window has predetermined starting and finishing times.
2. **Positive duration:** Each window satisfies \(s_i<f_i\).
3. **Equal contribution:** Every selected window contributes one unit to the objective.
4. **No overlapping selections:** The selected windows must be mutually compatible.
5. **No additional constraints:** There are no extra requirements involving window weights, queue sizes, transition delays, or required sequencing beyond interval compatibility.

These assumptions are essential.

For example, if windows have different priorities or values and the objective changes to maximizing total value, the earliest-finish-time greedy strategy is not necessarily optimal.

Similarly, if traffic signals require additional transition times between green phases, the model would need to incorporate those constraints explicitly.

## 8. Running-time relationship

The correctness proof establishes that the algorithm returns an optimal schedule.

Its running-time analysis is a separate argument.

Sorting the windows by finishing time requires

\[
O(n\log n)
\]

and examining each candidate window once requires

\[
O(n).
\]

Therefore,

\[
T(n)=O(n\log n)+O(n)
\]

and

\[
\boxed{T(n)=O(n\log n)}.
\]

The algorithm is both optimal for the stated mathematical objective and efficient to execute.

## 9. Conclusion

The earliest-finish-time greedy algorithm is optimal for maximum-cardinality interval scheduling.

The exchange argument proves that the first greedy selection can always replace the first interval of an optimal schedule without reducing the number of compatible windows.

The remaining problem retains the same structure, allowing the argument to be applied recursively. Induction then establishes correctness for every finite collection of valid candidate windows.

In the traffic signal scheduling application, this proves that the algorithm maximizes the number of compatible, preapproved green-light windows. It does not establish that the algorithm minimizes actual vehicle congestion or travel delays.
