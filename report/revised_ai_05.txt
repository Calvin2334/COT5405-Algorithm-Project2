## 3. Complete Python plotting program

Replace its contents with:

<CodeBlock language="python" editable>
import csv
from pathlib import Path

import matplotlib.pyplot as plt

# Locate files relative to this Python script
folder = Path(__file__).resolve().parent
csv_path = folder / "results.csv"
graph_path = folder / "runtime_graph.png"

sizes = []
times = []
theoretical = []

# Read benchmark results
with csv_path.open(newline="", encoding="utf-8") as file:
    reader = csv.DictReader(file)

    required = {"InputSize", "MedianTimeMs", "NLogN"}

    if reader.fieldnames is None:
        raise ValueError("CSV file is empty.")

    missing = required - set(reader.fieldnames)
    if missing:
        raise ValueError(f"Missing CSV columns: {sorted(missing)}")

    for row in reader:
        sizes.append(int(row["InputSize"]))
        times.append(float(row["MedianTimeMs"]))
        theoretical.append(float(row["NLogN"]))

if not sizes:
    raise ValueError("The CSV contains no benchmark results.")

# Sort all measurements by input size
data = sorted(zip(sizes, times, theoretical))
sizes, times, theoretical = map(list, zip(*data))

# Scale n log n to the last measured runtime
scale = times[-1] / theoretical[-1]
scaled_theory = [value * scale for value in theoretical]

# Generate figure
plt.figure(figsize=(9, 5))

plt.plot(
    sizes,
    times,
    marker="o",
    label="Measured median runtime"
)

plt.plot(
    sizes,
    scaled_theory,
    linestyle="--",
    label="Scaled O(n log n)"
)

plt.xlabel("Number of green-light windows (n)")
plt.ylabel("Execution time (ms)")
plt.title("Greedy Algorithm: Experimental Runtime Analysis")

plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()

# Save graph for the LaTeX report
plt.savefig(graph_path, dpi=300)

print(f"Graph saved to: {graph_path}")

plt.show()
</CodeBlock>

### Explanation of the Python code

**Step 1 — Read the CSV**

```python
with csv_path.open(newline="", encoding="utf-8") as file:
    reader = csv.DictReader(file)
```

`csv.DictReader` reads the CSV file and allows access to each column by name.

For example:

```python
times.append(float(row["MedianTimeMs"]))
```

retrieves the measured median runtime.

**Step 2 — Calculate the scaled theoretical curve**

```python
scale = times[-1] / theoretical[-1]
scaled_theory = [value * scale for value in theoretical]
```

The theoretical \(n\log_2(n)\) values are not measured in milliseconds.

We therefore multiply them by a scaling factor so that the theoretical curve matches the final experimental data point.

Mathematically:

\[
T_{\text{scaled}}(n)=c\,n\log_2(n)
\]

where

\[
c=\frac{T_{\text{measured}}(n_{\max})}
{n_{\max}\log_2(n_{\max})}
\]

This scaling is purely for visual comparison. It does not prove that the measured runtime follows \(n\log n\).

**Step 3 — Generate the graph**

`plt.plot()` creates the measured and theoretical curves, while `plt.xlabel()`, `plt.ylabel()`, and `plt.legend()` make the figure easier to interpret.

**Step 4 — Save the graph**

```python
plt.savefig(graph_path, dpi=300)
```

saves a high-resolution PNG named `runtime_graph.png`.

## 6. Common errors and troubleshooting

### Error A — Incorrect CSV header

Example:

```text
KeyError: 'MedianTimeMs'
```

**Cause:** The Python script expects the exact column name `MedianTimeMs`, but the CSV uses a different spelling or capitalization.

**Fix:** Open `Greedy/results.csv` and confirm the first row is:

```csv
InputSize,MedianTimeMs,NLogN
```

CSV column names are case-sensitive when accessed through a dictionary.

### Error B — Missing CSV file

Example:

```text
FileNotFoundError: [Errno 2] No such file or directory
```

**Cause:** `results.csv` does not exist in the expected location.

**Fix:** Make sure the C++ experiment has run successfully and generated the file.

The Python program above uses `Path(__file__)` to locate its folder, avoiding problems caused by running the script from different working directories.

### Error C — Empty CSV file

Example:

```text
ValueError: The CSV contains no benchmark results.
```

**Cause:** The CSV has no data rows or the benchmark did not complete successfully.

**Fix:** Run the C++ experiment again and confirm it produces seven rows of measurements.

### Error D — Matplotlib isn't installed

Example:

```text
ModuleNotFoundError: No module named 'matplotlib'
```

**Fix:** Install it using the same Python interpreter that runs your script:

```powershell
python -m pip install matplotlib
```

### Error E — Figure doesn't appear in Overleaf

**Cause:** The image is missing from the Overleaf project, its filename is incorrect, or images are disabled in draft mode.
