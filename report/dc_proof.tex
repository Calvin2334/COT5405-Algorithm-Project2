\subsection{Proof of Correctness}

For $\mathit{lo} \le \mathit{hi}$, let
$\mathcal{I}(\mathit{lo}, \mathit{hi}) = \{[l, r] : \mathit{lo} \le l \le r \le \mathit{hi}\}$.

\medskip
\noindent\textbf{Lemma 1 (Crossing periods).}
If $\mathit{lo} \le \mathit{mid} < \mathit{hi}$,
\textsc{Max-Crossing}$(X, \mathit{lo}, \mathit{mid}, \mathit{hi})$
returns a period $[l', r']$ with
$\mathit{lo} \le l' \le \mathit{mid} < r' \le \mathit{hi}$
and sum $s' = S(l', r')$ equal to
$\max \{ S(l, r) : \mathit{lo} \le l \le \mathit{mid} < r \le \mathit{hi} \}$.

\noindent\textbf{Proof.}
A crossing period splits into non-empty parts
$[l, \mathit{mid}]$ and $[\mathit{mid}+1, r]$, so
$S(l, r) = S(l, \mathit{mid}) + S(\mathit{mid}+1, r)$.
The first term depends only on $l$, the second only on
$r$, and every pair with $\mathit{lo} \le l \le \mathit{mid}$
and $\mathit{mid} < r \le \mathit{hi}$ is a crossing
period, so the two terms can be maximized independently.
In the first loop, after processing index $i$,
$\mathit{sum} = S(i, \mathit{mid})$ and
$\mathit{leftSum} = S(\mathit{bestL}, \mathit{mid})$ is the
maximum of $S(l, \mathit{mid})$ over
$i \le l \le \mathit{mid}$. This invariant holds after
the first iteration since $\mathit{leftSum}$ starts at
$-\infty$, and each iteration adds $X[i]$ to
$\mathit{sum}$ and updates $\mathit{leftSum}$ only on
improvement; at termination ($i = \mathit{lo}$) it gives
the best left part. A symmetric invariant holds for
$\mathit{rightSum}$, so
$s' = \mathit{leftSum} + \mathit{rightSum}$ is the
maximum crossing sum, attained by
$[\mathit{bestL}, \mathit{bestR}]$. \hfill $\square$

\medskip
\noindent\textbf{Theorem.}
For every $\mathit{lo} \le \mathit{hi}$,
\textsc{Max-Subarray}$(X, \mathit{lo}, \mathit{hi})$
returns a period in $\mathcal{I}(\mathit{lo}, \mathit{hi})$
whose reported sum equals its true sum and is maximum
over $\mathcal{I}(\mathit{lo}, \mathit{hi})$.

\noindent\textbf{Proof.}
By strong induction on $m = \mathit{hi} - \mathit{lo} + 1$.
If $m = 1$, $[\mathit{lo}, \mathit{lo}]$ is the only
period and is returned. If $m \ge 2$, then
$\mathit{lo} \le \mathit{mid} < \mathit{hi}$, so both
halves are non-empty and shorter than $m$. Every period
in $\mathcal{I}(\mathit{lo}, \mathit{hi})$ satisfies
exactly one of $r \le \mathit{mid}$, $l > \mathit{mid}$,
or $l \le \mathit{mid} < r$, so
\[
\mathcal{I}(\mathit{lo}, \mathit{hi}) =
\mathcal{I}(\mathit{lo}, \mathit{mid}) \cup
\mathcal{I}(\mathit{mid}+1, \mathit{hi}) \cup \mathcal{C},
\]
where $\mathcal{C}$ is the set of crossing periods. By
the inductive hypothesis $L$ and $R$ are optimal over
the two halves, and by Lemma~1 $C$ is optimal over
$\mathcal{C}$. The maximum over a union is the maximum
of the maxima, so the best of $L, R, C$ is optimal, and
each is a valid period with a correct sum.
\hfill $\square$

\medskip
With $\mathit{lo} = 1$ and $\mathit{hi} = n$, the
algorithm returns a period of maximum total queue
build-up; it terminates because every recursive call is
on a strictly shorter range.
