
\section{AI Tool Usage and Disclosure}

\subsection{AI Tool Used}

OpenAI ChatGPT was used during the development
of the greedy traffic signal scheduling project.

AI assistance included problem formulation,
mathematical abstraction, greedy algorithm
design, C++ implementation, debugging,
correctness proofs, runtime analysis,
experimental graph generation, and
LaTeX report preparation.

\subsection{Representative AI Interactions}

The following examples summarize selected
AI interactions during project development.

\begin{enumerate}

\item \textbf{Problem Formulation}

Prompt:
``what if i change it to the max amount of time
you can have lights running at the same time
to avoid cloging traffic''

Result:
ChatGPT suggested modeling the problem as
maximum-cardinality interval scheduling
using preapproved green-light windows.

\item \textbf{Greedy Algorithm}

Prompt:
``okay lets se''

Result:
ChatGPT explained the earliest-finish-time
greedy strategy and assisted with C++ code.

\item \textbf{Code Review}

Prompt:
``before i push it chekc my code correct what
needs to be correctedso i know im pushing
the full correct file''

Result:
ChatGPT reviewed code correctness,
initialization, and output formatting.

\item \textbf{Runtime Experiments}

Prompt:
``give me the whole code''

Result:
ChatGPT provided C++ benchmarking
assistance for measuring running time.

\item \textbf{Graph Generation}

Prompt:
``so run this python Greedy/plot\_results.py''

Result:
ChatGPT assisted with executing the Python
plotting script and generating the graph.

\item \textbf{Correctness Proof}

Prompt:
``so show me exactly what i should write''

Result:
ChatGPT assisted with the exchange-argument

\item \textbf{LaTeX Report}

Prompt:

\item \textbf{Revised Interaction 1}

Topic:

\end{enumerate}

\subsection{Development and Verification}

The C++17 greedy implementation was
compiled and tested.

Seven experimental input sizes ranging
from 1,000 to 200,000 windows were used.

Each input size was measured ten times,
and median execution times were recorded.

Python and Matplotlib were used to
generate the experimental runtime graph.

The measurements were consistent with
the theoretical $O(n\log n)$ running time.
