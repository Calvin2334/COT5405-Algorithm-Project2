### How `\input` works

In `main.tex`, writing

```latex
\input{greedy_problem}
```

inserts the contents of `greedy_problem.tex` at that location in the document.

This is similar to separating a software project into multiple source files: each file handles a particular section, while `main.tex` determines the overall order.

The section files should contain their respective section content, not separate `\documentclass` or `\begin{document}` commands.

## 5. Including the experimental runtime graph

Your runtime graph is stored as:

`runtime_graph.png`

The corresponding LaTeX code in `greedy_runtime.tex` can be:

<CodeBlock language="latex" editable>
\begin{figure}[htbp]
    \centering

    \includegraphics[
        width=\linewidth
    ]{runtime_graph.png}

    \caption{Measured median runtime of the
    greedy scheduling algorithm compared
    with scaled $O(n\log n)$ growth.}

    \label{fig:greedy-runtime}
\end{figure}
</CodeBlock>

The command `\includegraphics` inserts the image, while `width=\linewidth` scales it to the available column width.

In IEEE conference format, figures normally occupy one column. If the figure is too wide, it may require a two-column `figure*` environment instead.

Use `\label` and `\ref` to refer to the figure:

```latex
Figure~\ref{fig:greedy-runtime}
shows the empirical runtime comparison.
```

Avoid manually inserting repeated blank lines to position the graph; LaTeX controls figure placement.

## 6. Including C++ and Python code in an appendix

The `listings` package lets you include source files directly without copying their contents into the LaTeX editor.

For example, create a file called `greedy_code_appendix.tex` containing:

<CodeBlock language="latex" editable>
\section{Greedy Algorithm Source Code}

This appendix contains the C++17
greedy implementation, benchmark code,
and Python graph-generation script.

\subsection{Greedy Implementation}

\lstinputlisting[
    language=C++,
    caption={Greedy scheduling implementation},
    label={lst:greedy}
]{code/greedy.cpp}

\subsection{Experimental Benchmark}

\lstinputlisting[
    language=C++,
    caption={Experimental benchmark},
    label={lst:benchmark}
]{code/experiment.cpp}

\subsection{Graph Generation}

\lstinputlisting[
    language=Python,
    caption={Runtime graph generation},
    label={lst:plot}
]{code/plot_results.py}
</CodeBlock>

**Important:** These paths assume the files are inside a folder named `code`.

If the C++ and Python files are in the same folder as `main.tex`, remove `code/` from their paths. Otherwise, LaTeX will not find them.

You can also reduce the code font to `\tiny` for especially long lines, but keeping the code readable is preferable.
