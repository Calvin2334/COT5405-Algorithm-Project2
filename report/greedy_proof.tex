\subsection{Proof of Correctness}
\label{sec:greedy-proof}

\noindent\textbf{Theorem.} For any set
$W = \{w_1, \ldots, w_n\}$ of candidate windows with
$s_i < f_i$, the earliest-finish-time greedy algorithm
produces a maximum-cardinality subset of mutually
compatible windows.

\medskip
\noindent\textbf{Proof.}
Let $g$ be the window with the earliest finishing time,
and let $O = (o_1, \ldots, o_k)$ be an optimal schedule
ordered by time. Since $g$ finishes earliest,
$f(g) \leq f(o_1)$. Replacing $o_1$ with $g$ keeps the
schedule compatible, because every later window in $O$
starts at or after $f(o_1) \geq f(g)$, and it keeps the
size at $k$. Hence some optimal schedule contains the
greedy choice $g$.

After selecting $g$, the algorithm considers only
windows starting at or after $f(g)$, which is a smaller
instance of the same problem. Applying the same
exchange argument to the remaining windows (by
induction on $n$) shows that every greedy choice can
be included in an optimal schedule. Therefore the
algorithm returns a maximum-cardinality set of
mutually compatible windows. \hfill $\square$
