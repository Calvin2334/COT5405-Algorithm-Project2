\subsection{Real-World Problem Description}

Traffic congestion is common at urban intersections
controlled by traffic signals. Poorly coordinated
signals cause vehicles to stop repeatedly, increase
waiting times, and add to congestion along major
roads, for example when one intersection releases
vehicles that an intersection farther down the road
cannot accommodate. Signal coordination synchronizes
intersections to improve progression and reduce
unnecessary stops and delays \cite{fhwa2008}.

We consider a simplified scheduling problem. A traffic
management system provides a collection of candidate
green-light time windows for a traffic movement, each
an interval during which a green-light opportunity
could be scheduled. The system must select a subset of
windows such that no two selected windows overlap,
maximizing the number of selected windows. We assume
all windows have equal importance, each window is
indivisible, and the safety and feasibility of every
window have already been verified. Real coordination
also involves traffic volume, vehicle speeds,
pedestrian crossings, and intersection capacity; the
abstraction isolates an optimization problem that a
greedy algorithm solves optimally.

\subsection{Mathematical Abstraction}

The candidate windows form a set of time intervals
$W = \{w_1, \ldots, w_n\}$ with $w_i = (s_i, f_i)$,
where $s_i < f_i$ are the start and finish times of
window $i$. Two windows $w_i$ and $w_j$, with $w_i$
scheduled first, are \emph{compatible} if they do not
overlap, i.e., $f_i \leq s_j$: the next window may
begin only after the previous one finishes. The goal
is to find a subset $S \subseteq W$ of mutually
compatible windows maximizing $|S|$. This is the
maximum-cardinality interval scheduling problem.
